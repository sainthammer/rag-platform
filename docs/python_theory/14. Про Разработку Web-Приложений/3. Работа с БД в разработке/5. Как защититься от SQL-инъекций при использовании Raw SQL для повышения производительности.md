
# в SQL Alchemy:

для передачи Raw SQL как правило мы используем метод text()

Для защиты от SQL-инъекций при использовании метода `text()` в SQLAlchemy необходимо применять параметризованные запросы, которые позволяют отделить данные от структуры SQL-запроса. Метод `text()` предоставляет безопасный способ подстановки значений через привязку параметров, защищая от SQL-инъекций.

### Как использовать параметризацию в `text()`

При создании SQL-запроса через `text()` вы можете использовать специальные параметры (так называемые **bind parameters**), обозначенные двоеточием (`:parameter_name`), чтобы указать, какие значения будут переданы в запрос. SQLAlchemy самостоятельно подставит значения безопасным образом, исключая прямую вставку данных в текст SQL-запроса.

#### Пример безопасного запроса с параметрами:

```python

from sqlalchemy import text

# Пример небезопасного запроса
# query = text("SELECT * FROM users WHERE username = '{}'".format(username))

# Пример безопасного параметризованного запроса
query = text("SELECT * FROM users WHERE username = :username")
result = connection.execute(query, {"username": username})


```

Здесь `:username` — это параметр привязки, который предотвращает SQL-инъекцию, так как пользовательский ввод (`username`) передается как параметр, а не как часть SQL-запроса.

### Основные способы защиты при использовании `text()`

1. **Использование параметров привязки**: Всегда используйте двоеточие и название параметра (`:parameter_name`) для подстановки значений, вместо вставки значений напрямую в текст SQL-запроса.

```python

query = text("SELECT * FROM products WHERE price > :min_price AND category = :category")
result = connection.execute(query, {"min_price": 100, "category": "electronics"})


```

2. **Передача параметров через словарь**: Для передачи значений в запрос используйте словарь, как во втором аргументе `execute()`, или передавайте параметры через `bindparams` для более сложных запросов.

```python

query = text("SELECT * FROM orders WHERE order_date > :order_date")
query = query.bindparams(order_date="2024-01-01")
result = connection.execute(query)

```

### Антипаттерны, которых следует избегать

- **Непосредственная конкатенация строк**: Никогда не используйте Python-строковую интерполяцию или конкатенацию для вставки пользовательских значений. Это позволяет злоумышленнику вводить SQL-код.

```python

# Небезопасный способ 
query = text(f"SELECT * FROM users WHERE username = '{username}'")

```

- **Использование `.format()` и `%` для подстановки строк**: Эти методы также подвержены SQL-инъекциям, так как данные напрямую вставляются в SQL-запрос.
    

### Когда `text()` безопасен

Метод `text()` SQLAlchemy безопасен для использования при условии, что для всех пользовательских данных используются параметры привязки. SQLAlchemy автоматически подставляет параметры в запрос с экранированием и защитой от SQL-инъекций.
