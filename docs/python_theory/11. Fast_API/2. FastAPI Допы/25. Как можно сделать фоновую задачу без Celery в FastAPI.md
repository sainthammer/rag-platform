
#### Ответ для собеседования

Фоновые задачи реализованы при помощи сущности `BackgroundTasks`, которая позволяет выполнять задачу после того, как клиент получил ответ на запрос. Такие задачи исполняются в отдельном потоке.

#### Подробный ответ

FastAPI позволяет создавать фоновые задачи с использованием класса `BackgroundTasks`. Чтобы создать задачу, сначала импортируйте `BackgroundTasks` из `fastapi` и определите свою функцию для задачи. Например, если вы хотите логировать что-то в фоновом режиме, определите функцию `write_log`. Теперь включите `BackgroundTasks` в качестве параметра в функцию операции с путем. Внутри этой функции используйте метод add_task объекта `BackgroundTasks`, чтобы добавить функцию записи журнала в качестве задачи. Это выполнит задачу после отправки ответа.

Вот пример:

```python

from fastapi import FastAPI, BackgroundTasks

# функция для записи логов в файл
def write_log(message: str):
    with open("log.txt", "w") as file:
        file.write(message)

app = FastAPI()

@app.post("/send/{message}")
async def send_message(message: str, background_tasks: BackgroundTasks):
    # задача добавится в очередь, но будет выполнена только после получения клиентом ответа
    background_tasks.add_task(write_log, message)
    return {"Message": "Message sent!"}

```

Для фоновых/асинхронных задач можно использовать такую библиотеку как `celery`, что даже предпочтительней для серьезных проектов.
