
### Описание `TypeVar()` :

Тип аннотации [`TypeVar()`](https://docs-python.ru/standart-library/modul-typing-python/tip-annotatsii-typevar-modulja-typing/ "Тип аннотации TypeVar модуля typing в Python.") модуля [`typing`](https://docs-python.ru/standart-library/modul-typing-python/ "Модуль typing в Python, аннотации типов.") представляет собой - возможные типы переменных.

При желании и _для совместимости с Python<=3.12_, переменные типа многократного использования можно создать вручную, например:

```python

T = TypeVar('T')  # Может быть что угодно
A = TypeVar('A', str, bytes)  # Должно быть `str` или `bytes`
S = TypeVar('S', bound=str)  # Может быть любым подтипом `str`

```

Пример использования:

```python

from typing import TypeVar

T = TypeVar("T")

def identity(arg: T) -> T:
    return arg


```
