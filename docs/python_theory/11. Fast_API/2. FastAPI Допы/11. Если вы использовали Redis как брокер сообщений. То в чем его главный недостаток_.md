
Redis можно использовать как брокер сообщений, в нем есть специальные инструменты, это допустимо в рамках нашего учебного проекта. Однако в реальном продакшене вы такого не встретите. Причина проста, у использования Redis в качестве брокера сообщений есть существенный минус - **он не дает 100% гарантии доставки сообщения**, поэтому лучше использовать специально заточенные под это программы (брокеры сообщений), например RAbbitMQ, а вообще круто Кафку (Apache Kafka).
