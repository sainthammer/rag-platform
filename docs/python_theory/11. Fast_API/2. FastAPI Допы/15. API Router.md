
APIRouter позволяет вам создавать отдельные маршрутизаторы (url'ы) для разных частей вашего API. Этот модульный подход не только сохраняет ваш код чистым и поддерживаемым, но и позволяет вам группировать связанные маршруты.

Основные преимущества: 

- Модульность: разбейте приложение на логические разделы. 
- Повторное использование: повторно используйте маршрутизаторы в разных частях приложения. 
- Поддерживаемость: проще поддерживать и управлять маршрутами.

Самый базовый пример создание простого роутера:

```python

from fastapi import APIRouter, FastAPI

app = FastAPI()
router = APIRouter()


@router.get("/users/", tags=["users"])
async def read_users():
    return [{"username": "Rick"}, {"username": "Morty"}]


app.include_router(router)

```
