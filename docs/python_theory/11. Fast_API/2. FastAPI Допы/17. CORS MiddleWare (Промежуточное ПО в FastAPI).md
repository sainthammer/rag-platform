
FastAPI имеет встроенное промежуточное ПО для управления CORS, которое можно добавить в экземпляр приложения. Чтобы включить его, импортируйте `CORSMiddleware` из `fastapi.middleware.cors` и добавьте его в свое приложение FastAPI с помощью метода `.add_middleware()`. Вам необходимо указать такие параметры, как `allow_origins` (список разрешенных доменов и IP адресов), `allow_credentials` (поддерживаются ли файлы cookie), `allow_methods` (разрешенные HTTP методы),и `allow_headers` (какие HTTP-заголовки разрешены). Вот пример:

```python

from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

origins = ["http://localhost:3000"]

app.add_middleware(
    CORSMiddleware,
    allow_origins=origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

@app.get("/")
async def main():
    return {"message": "Hello World"}

```
