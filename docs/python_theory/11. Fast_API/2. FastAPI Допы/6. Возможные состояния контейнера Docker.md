
1. **Created** — контейнер создан, но не активен.
   
2. **Restarting** — контейнер в процессе перезапуска.
   
3. **Running** — контейнер работает.
   
4. **Paused** — контейнер приостановлен.
   
5. **Exited** — контейнер закончил свою работу.
   
6. **Dead** — контейнер, который сервис попытался остановить, но не смог.
