
Celery Beat работает с использованием выделенного рабочего процесса (worker), который работает в фоновом режиме и опрашивает очередь задач, чтобы найти задачи, которые необходимо выполнить. Сами задачи определяются в Celery как функции или методы и могут быть запланированы для запуска в определенное время или интервалы с использованием простого синтаксиса.
