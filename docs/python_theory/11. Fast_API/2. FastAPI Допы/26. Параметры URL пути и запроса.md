
# Как параметры пути и параметры запроса используются в FastAPI?

FastAPI использует параметры пути и параметры запроса для извлечения данных из URL-адреса. Параметры пути определяются в URL-адресе маршрута, заключенном в фигурные скобки {}. Они используются для получения определенных значений из самого пути. Например, `@app.get("/items/{item_id}")` будет использовать параметр `item_id` из URL-адреса.

С другой стороны, параметры запроса добавляются после URL-адреса после вопросительного знака "?". Они позволяют передавать в функцию дополнительную информацию. Например, `@app.get("/items/")` может принимать "skip" и "limit" в качестве параметров запроса для управления нумерацией страниц.

В обоих случаях FastAPI автоматически проверяет эти параметры, генерирует сообщения об ошибках, если данные недействительны, и предоставляет для них интерактивную документацию.

Вот небольшой пример на использование параметров пути и параметров запроса:

```python

@app.get("/items/{item_id}")
def get_item_by_id(item_id: int = Path(...)):
    return {"item_id": item_id}


@app.get("/items")
def get_items(skip: int = Query(...), limit: int = Query(...)):
    return items[skip * limit + 1 : skip * limit + 1 + limit]
    
```
