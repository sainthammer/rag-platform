
Docker позволяет нам установить файловое хранилище одного из 3 типов:

volume (том): специальные директории на хостовой машине или удаленном сервере, которые монтируются в контейнер. Они обеспечивают постоянное хранение данных и могут использоваться для обмена данными между контейнерами.

bind mount имеют ограниченную функциональность по сравнению с томами. При использовании связанного монтирования файл или каталог на хост-машине монтируется в контейнер. Файл или каталог ссылаются по его абсолютному пути на хост-машине. Напротив, при использовании тома новый каталог создается в каталоге хранения Docker на хост-машине, и Docker управляет содержимым этого каталога. Это позволяет контейнерам иметь доступ к данным на хостовой машине и делиться данными между несколькими контейнерами.

tempfs mounts - является временным и сохраняется только в памяти хоста. Когда контейнер останавливается, монтирование tmpfs удаляется, и записанные там файлы не сохраняются. Они полезны для хранения временных данных, которые не нужно сохранять между запусками контейнеров.
