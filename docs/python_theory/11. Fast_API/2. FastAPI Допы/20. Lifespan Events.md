
Вы можете определить логику (код), которая должна быть выполнена до запуска приложения. Это означает, что этот код будет выполнен один раз, до того, как приложение начнет получать запросы.

Таким же образом вы можете определить логику (код), которая должна быть выполнена при завершении работы приложения. В этом случае этот код будет выполнен один раз, после обработки, возможно, многих запросов.

Поскольку этот код выполняется до того, как приложение начнет принимать запросы, и сразу после того, как оно закончит обработку запросов, он охватывает весь жизненный цикл приложения (слово «жизненный цикл» будет важным через секунду 😉).

Это может быть очень полезно для настройки ресурсов, которые вам нужно использовать для всего приложения, и которые являются общими для запросов и/или которые вам нужно очистить впоследствии. Например, пул соединений с базой данных или загрузка общей модели машинного обучения.

# Использование

Представим, что мы пишем приложение, в процессе выполнения которого мы мы будем делать машинное обучение нейросети (ML). Как нам это сделать так, чтобы модельки подрузились заранее, а при завершении работы закрылись:


```python

from contextlib import asynccontextmanager

from fastapi import FastAPI


def fake_answer_to_everything_ml_model(x: float):
    return x * 42


ml_models = {}


@asynccontextmanager
async def lifespan(app: FastAPI):
    # Load the ML model
    ml_models["answer_to_everything"] = fake_answer_to_everything_ml_model
    yield
    # Clean up the ML models and release the resources
    ml_models.clear()


app = FastAPI(lifespan=lifespan)


@app.get("/predict")
async def predict(x: float):
    result = ml_models["answer_to_everything"](x)
    return {"result": result}

```
