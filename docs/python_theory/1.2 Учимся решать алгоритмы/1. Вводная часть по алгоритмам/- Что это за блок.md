
Это краткая выжимка из [курса видосов](https://www.youtube.com/playlist?list=PL6Wui14DvQPySdPv5NUqV3i8sDbHkCKC5) на ютуб по написанию алгоритмических задач. Поэтому существует данный блок. Чтобы вы научились вообще писать алгоритмические задачки, поняли лучше, что хотят от вас на этапах, которые им посвящены. Также советы по тому, как и где тренироваться до собеседований писать эти задачки.
