В целом мы и применяем ORM для работы с СУБД. Вплоть до создания с нуля целых БД. Поэтому в теории ORM нам должна обеспечивать возможность любых манипуляций с БД. Просто иногда их сложнее реализовать чем через обычный raw SQL, чем понять, как это делается с помощью ORM. Вообще сами СУБД более гибкие, чем ORM, то есть сделать очень сложные миграции или запросы будет проще через саму СУБД.
