
нет, нельзя, тогда кортеж станет изменяемым, так как в нем содержится изменяемый тип данных (список), то нормально hash работать не будет

Я проверил в PyCharm'е эту информацию:

пока все работает:

```python

a = (1 , 2)
print(hash(a))

# Вывод:
# >>> -3550055125485641917

```

а теперь добавим в состав tuple какой-нибудь list и `п*здец`

```python

b = (1 , 2, [3, 4])
print(hash(b))

# Вывод:
#     print(hash(b))
           ^^^^^^^
# TypeError: unhashable type: 'list'


```
