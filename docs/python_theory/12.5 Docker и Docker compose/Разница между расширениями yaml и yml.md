
Кратко: никакой разницы нет.

Расширения файлов не оказывают никакого влияния на содержимое файла. Вы можете хранить содержимое YAML в файлах с любым расширением: .yml, .yaml или любым другим. Но все же FAQ по YAML рекомендует использовать .yaml вместо .yml, но по историческим причинам многие программисты Windows все еще боятся использовать расширения с более чем тремя символами и поэтому предпочитают использовать .yml.
