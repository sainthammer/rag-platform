
# Математические функции

Для большинства математических вычислений, таких как получение степени числа или получение квадратного корня, в SQL есть встроенные числовые функции. Вот некоторые примеры данных функций:

|Имя функции|Описание|
|:--|---|
|[POW(num, power)](https://sql-academy.org/handbook/pow)|Вычисляет число в указанной степени|
|[SQRT(num)](https://sql-academy.org/handbook/sqrt)|Вычисляет квадратный корень числа|
|[LOG(base, num)](https://sql-academy.org/handbook/log)|Вычисляет логарифм числа по указанному основанию|
|[EXP(num)](https://sql-academy.org/handbook/exp)|Вычисляет enum|
|[SIN(num)](https://sql-academy.org/handbook/sin)|Вычисляет синус числа|
|[COS(num)](https://sql-academy.org/handbook/cos)|Вычисляет косинус числа|
|[TAN(num)](https://sql-academy.org/handbook/tan)|Вычисляет тангенс числа|

Список всех числовых функций, их описание и примеры можно посмотреть в [справочнике](https://sql-academy.org/handbook/ceiling).
