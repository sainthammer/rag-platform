
> [!Кратко]
> EXIST работает как условный оператор, который возвращает TRUE, когда запрос внутри возвращает одну или больше записей, а когда запрос не дает ни одной строки, возвращает FALSE,
> НО! В реальных запросах он может применяться как фильтр в WHERE.

У оператора очень интересная логика работы в SQL запросах, читаем [статью](https://habr.com/ru/articles/756198/)
