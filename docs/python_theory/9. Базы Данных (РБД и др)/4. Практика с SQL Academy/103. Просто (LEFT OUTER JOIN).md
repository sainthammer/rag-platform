
# Формулировка

Вывести список имён сотрудников, получающих большую заработную плату, чем у непосредственного руководителя.

Поля в результирующей таблице:

name

Формат ожидаемого результата запроса:

| name   |
| ------ |
| NAME 1 |
| NAME 2 |

# Моё решение

```sql

SELECT DISTINCT e1.name FROM Employee e1
LEFT OUTER JOIN Employee e2 ON e1.chief_id = e2.id
WHERE e1.chief_id IS NOT NULL 
AND e1.chief_id = e2.id 
AND e1.salary > e2.salary;

```
