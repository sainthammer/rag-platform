
# Формулировка

Добавьте товар с именем "Cheese" и типом "food" в список товаров (Goods).

В качестве первичного ключа (good_id) укажите количество записей в таблице + 1.

# Моё решение

```sql

INSERT INTO Goods
    SET 
        good_id = (SELECT COUNT(*) + 1 FROM Goods g),
        good_name = 'Cheese',
        type = 2;

```
