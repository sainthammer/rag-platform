
# Формулировка

Выведите отсортированный список (по возрастанию) фамилий и имен студентов в виде Фамилия.И.

Поля в результирующей таблице:

name

# Моё решение

```sql

SELECT CONCAT(last_name, '.', LEFT(first_name, 1), '.') AS name FROM Student
ORDER BY name;

```

Пояснение

В функции CONCAT(str1, str2, ...) просто происходит объединение строк, а функция LEFT(_string_, _number_of_chars_) делает срезку из строки string на number_of_chars , в нашем случае получается 1-ая буква имени
