# Формулировка

Для каждой комнаты, которую снимали как минимум 1 раз, найдите имя человека, снимавшего ее последний раз, и дату, когда он выехал

Поля в результирующей таблице:

room_id

name

end_date

Используйте конструкцию "as room_id" для вывода идентификатора комнаты

# Моё решение

```sql

SELECT rs.room_id, name, date AS end_date
FROM (
    SELECT room_id, MAX(end_date) AS 'date'
    FROM Reservations
    GROUP BY room_id
     ) rs
JOIN Reservations rsv ON rs.room_id = rsv.room_id
AND rs.date = rsv.end_date
JOIN Users us ON rsv.user_id = us.id;

```

Пояснение 

1) Во FROM мы помещаем подзапрос, который даст нам на выходе таблицу, у которой только самые последние даты съема комнат. И ей мы даем псевдоним (alies) rs
