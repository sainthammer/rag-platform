
# Формулировка

Выведите название страны, где находится город «Salzburg»

Поля в результирующей таблице:

country_name

Формат ожидаемого результата запроса:

| country_name |
| ------------ |
| Germany      |

# Моё решение

```sql

SELECT Countries.name AS 'country_name'
FROM Countries
JOIN Regions ON Regions.countryid = Countries.id
JOIN Cities ON Cities.regionid = Regions.id
WHERE Cities.name = "Salzburg";

```
