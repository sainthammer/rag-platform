
# Формулировка

Выведите заполненность классов в порядке убывания

Поля в результирующей таблице:

name

count

Используйте конструкцию "as count" для агрегатной функции подсчета числа учащихся в классах. Это необходимо для корректной проверки.

# Моё решение

```sql

SELECT Class.name, COUNT(*) AS 'count' FROM Class
JOIN Student_in_class ON Student_in_class.class = Class.id
JOIN Student ON Student.id = Student_in_class.student
GROUP BY Class.name
ORDER BY count DESC;
