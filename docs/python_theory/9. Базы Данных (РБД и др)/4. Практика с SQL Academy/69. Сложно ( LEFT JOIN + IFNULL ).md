# Формулировка

Вывести идентификаторы всех владельцев комнат, что размещены на сервисе бронирования жилья и сумму, которую они заработали

Поля в результирующей таблице:

owner_id

total_earn

Используйте конструкцию "as owner_id" и "as total_earn" для вывода идентификаторов владельцев и заработанной суммы соответственно.

# Моё решение

```sql

SELECT owner_id, IFNULL(SUM(total), 0) AS 'total_earn' FROM Rooms
LEFT JOIN Reservations ON Reservations.room_id = Rooms.id
GROUP BY owner_id
ORDER BY total_earn DESC;

```

Пояснение 

1) Мы используем LEFT JOIN, чтобы получилось так, если комнату даже не снимали, у неё все равно есть записи с NULL, и теперь можно через IFNULL написать, что она заработала 0 денег.
