
# Формулировка

Добавьте в список типов товаров (GoodTypes) новый тип "auto".

В качестве первичного ключа (good_type_id) укажите количество записей в таблице + 1.

# Моё решение

```sql

INSERT INTO GoodTypes
    SET 
        good_type_id = (
            SELECT COUNT(*) + 1 FROM GoodTypes gt
            ),
        good_type_name = 'auto';

```
