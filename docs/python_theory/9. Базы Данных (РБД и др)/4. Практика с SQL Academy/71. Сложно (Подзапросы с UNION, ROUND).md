# Формулировка

Найдите какой процент пользователей, зарегистрированных на сервисе бронирования, хоть раз арендовали или сдавали в аренду жилье. Результат округлите до сотых.

Поля в результирующей таблице:

percent

Используйте конструкцию "as percent" для вывода процента активных пользователей. Пример формата ответа: 65.23

# Моё решение

```sql

SELECT ROUND((
    SELECT COUNT(*) FROM (
        SELECT DISTINCT owner_id FROM Rooms rm
        JOIN Reservations rs ON rm.id = rs.room_id
        UNION
        SELECT user_id
        FROM Reservations
        ) active_users
    ) * 100 / (
        SELECT COUNT(*) FROM Users
        ),
    2
) AS percent;

```

Пояснение 

1) Мы в 1-ом подзапросе находим всех уникальных владельцев, 
2) затем  UNION объединяем этот список с id людей, которые что-то снимали. 
3) Затем мы их считаем с помощью COUNT. Затем мы умножаем на 100
4) и делим на общее количество пользователей (его тоже через подзапрос) в БДшке, получаем проценты, 
5) затем мы округляем их до 2 знаков после запятой через ROUND
