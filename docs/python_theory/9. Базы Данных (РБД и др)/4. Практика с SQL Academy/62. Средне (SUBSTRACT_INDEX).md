
# Формулировка

Вывести в порядке убывания популярности доменные имена 2-го уровня, используемые пользователями для электронной почты. Полученный результат необходимо дополнительно отсортировать по возрастанию названий доменных имён.

Поля в результирующей таблице:

domain

count

Для эл. почты index@gmail.com доменным именем 2-го уровня будет gmail.com.

# Моё решение

```sql

SELECT SUBSTRING_INDEX(email, '@', -1) AS 'domain', COUNT(*) AS 'count' FROM Users
GROUP BY domain
ORDER BY count DESC,
domain ASC;

```

Пояснение

У функции SUBSTRING_INDEX(str, index, number) есть 3 аргумента на входе

- str -строка, с которой мы будем делать "срезку"
- index - это символ или подстрока, по которой осуществляется "срезка"
- number - это количество, с какого встреченного "индекса" мы возвращаем строку, если число отрицательное, то строка считывается с конца, и в итоге мы получим mail.com часть
