
# Формулировка

Удалить компании, совершившие наименьшее количество рейсов.

# Моё решение

```sql

DELETE FROM Company
WHERE id IN (
    SELECT company FROM Trip
    GROUP BY company
    HAVING COUNT(*) = (
        SELECT COUNT(*) AS 'count' FROM Trip
        GROUP BY company
        ORDER BY count
        LIMIT 1
        )
    );

```

Пояснение:

1) В последнем подзапросе мы находим наименьшее среди компаний по количеству рейсов, 
   
2) На уровень выше мы находим все id компаний, у который такое же количество рейсов как у найденного минимума,
   
3) На уровне DELETE мы просто удаляем строки, где id кампаний входят в результат подзапроса
