
Как правило в СУБД есть функция резервного копирования. В результате её выполнения мы сохраняем данные в момент создания резевной копии. Но что это такое физически?

Короче, по сути это просто текстовый файл кучей SQL операций. Сначала, когда мы делаем восстановление из нашей резервной копии делается DROP всех таблиц, затем они заново создаются с нужными нам ограничениями и связями. И делает просто куча INSERT вставок данных.
