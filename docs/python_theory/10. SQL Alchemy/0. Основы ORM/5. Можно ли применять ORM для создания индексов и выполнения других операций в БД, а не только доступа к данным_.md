Поэтому в теории ORM нам должна обеспечивать возможность любых манипуляций с БД. Просто иногда их сложнее реализовать чем через обычный raw SQL, чем понять, как это делается с помощью ORM.

На примере SQL Alchemy нашёл 2 способа создания индексов:

```python

from sqlalchemy import Index 


index = Index('index__phrase__en_phrases__ru_phrases', 
			  Phrase.en_phrase, Phrase.ru_phrase)
index.create(bind=db)
# выведет: Index('index__en_phrases__ru_phrases', Column('en_phrase', Text(), table=<phrases>), Column('ru_phrase', Text(), table=<phrases>))


```

class Other(Base):
