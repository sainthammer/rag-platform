
SQLAlchemy библиотека состоит из двух компонентов — SQLAlchemy Core и SQLAlchemy ORM.

# SQLAlchemy **Core**

SQLAlchemy **Core** — это как бы абстракция над SQL. Компонент умеет общаться с SQL и превращать Python-код в понятные для баз данных запросы с помощью SQL Expression Language. При этом он понимает, с каким именно видом хранилища данных взаимодействует.

- ядро рендеринга SQL;
- интеграцию DBAPI и транзакций;
- сервисы описания схем.

SQLAlchemy Core ближе к сырому SQL. Операторы языка в Core переводятся в необработанные SQL-запросы через специальные механизмы.

# SQLAlchemy **ORM**

SQLAlchemy **ORM** — удобный для разработчика интерфейс для управления базами данных. Компонент позволяет работать с ними и коммитить запросы прямо в Python-коде — без необходимости переписывать всё на язык SQL.

SQLAlchemy ORM - это API более высокого уровня, созданный на основе SQLAlchemy Core, обеспечивающий более простой способ взаимодействия с базами данных с использованием классов и объектов Python. Он позволяет сопоставлять классы Python с таблицами базы данных и взаимодействовать с данными в этих таблицах, используя экземпляры этих классов. Это может упростить операции с базой данных и позволить вам писать больше кода на Python. ORM также предоставляет ряд расширенных функций, таких как отложенная загрузка, кэширование и контроль транзакций, что делает его мощным инструментом для управления приложениями, управляемыми базой данных.

Понимание его особенностей и преимуществ

ORM (Object-Relational Mapper) — это API высокого уровня, который позволяет разработчикам взаимодействовать с базой данных с помощью объектов Python. Он предоставляет набор классов, соответствующих таблицам в базе данных, и эти классы можно использовать для создания, извлечения, обновления и удаления записей в базе данных.

Одной из основных особенностей ORM является возможность взаимодействия с базой данных с помощью объектов Python. Это обеспечивает более интуитивный и питонический способ работы с данными, позволяя разработчикам сосредоточиться на логике приложения, а не беспокоиться о тонкостях SQL. ORM также избавляет от необходимости писать простые операторы SQL, делая его более доступным для разработчиков, не знакомых с SQL.

Еще одна важная особенность ORM — автоматическое сопоставление объектов Python и строк базы данных. Это обрабатывается самим ORM, который занимается переводом между объектами Python и строками базы данных. Это устраняет необходимость ручного сопоставления и уменьшает объем шаблонного кода, который необходимо написать.

ORM также повышает удобство процесса разработки. Он обеспечивает более высокий уровень абстракции, что упрощает анализ данных и логики приложения, а также предоставляет множество готовых функций, таких как поддержка транзакций и пулов соединений.
