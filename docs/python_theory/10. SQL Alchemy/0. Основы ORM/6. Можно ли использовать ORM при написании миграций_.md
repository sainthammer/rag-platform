
Миграция базы данных — это изменение структуры или данных от одной версии до другой. При релизе версия базы данных должна соответствовать версии кода, иначе приложение не будет правильно работать. С этой целью и пишутся миграции БД.

Также миграции нужны для того, чтобы всегда можно было создать с нуля базу данных со структурой и данными cамой последней версии. Это необходимо при развертывании новой копии приложения.

# Ответ:

Это возможно, Но зависит от ORM. На примере SQL Alchemy для этого вам понадобить установить отдельно подпрограмму под названием Alembic. Связать его с моделями SQLAlchemy и сделать миграции. 

Но при написании миграции не рекомендуют использовать ORM. Как мне лично сказал Senior Python разработчик ORM'ки не очень гибкие, поэтому хорошие БДшники не используют их, а осуществляют миграции средствами СУБД. 

Описание сущности ORM изменяется со временем и миграция успешно выполняющаяся ранее, может выдавать ошибку в новой версии кода (может быть добавлено обязательное поле которого раньше не было и т.п.);
