## Задание 0:

### Задача:

Вам нужно почитать документацию/почитать статью/посмотреть видео на тему инициализации и запуска Airflow. Вам нужно добиться, чтобы Airflow работал в docker compose.

### Критерии готовности:

У вас успешно БЕЗ ОШИБОК работают контейнеры:

airflow-init
airflow-webserver
airflow-scheduler
postges

## Задание 1:

### Задача:

Настроить подключение Airflow + PostgreSQL.
Скопируйте какой-нибудь простенький SQL'ный DAG. И попробуйте отправить этот запрос на свою БД.

### Критерии готовности:

Запрос проходит. В логах Airflow нет ошибок.

## Задание 2:

Вам нужно написать DAG, который будет писать в логах тасок имя пользователя с приветствием. Например: "Привет, Жога!"

## Задание 3:

Вам нужно написать DAG, который будет записывать имя пользователя в БД.

## Задание 4:

Вам нужно написать DAG, который будет писать в логах тасок имя пользователя с приветствием. Например: "Привет, Жога!" Только теперь имя пользователя будет доставаться из БД.

Ещё вы можете сделать так, чтобы этот DAG срабатывал сразу после завершения DAG'а из предыдущего задания.

## Задание 5:

Теперь вам нужно добавить S3 хранилище MiniO в нашу сборку. Все также должно работать в docker compose.
Настройте подключение к MiniO в AirFlow GUI.
Не забудьте настроить и сам MiniO GUI. Добавьте bucket.

## Задание 6:

Сделайте DAG, который отслеживает появление в S3 хранилище какого-нибудь файла, например "trigger_file.txt".

## Задание 7:

Сделайте DAG, который загружает в S3 какой-нибудь файл.

## Задание 8:

Сделайте DAG, который может выполнять только одну из нескольких тасок в зависимости от результата предыдущей (ветвление). Можно использовать генератор случайных чисел для того, чтобы результат был непредсказуемым. 

## Задание 9:

Объедините накопленные знания. Сделайте DAG который ждет файл в S3 с какой-то полезной датой в виде .csv, затем, когда файл появляется, он что-то вычисляет с этими данными, записывает результат вычисления в БД. А если файл не появляется определенное время, то запускается другая таска. которая выводит в лог сообщение об ошибке.

## Задание 10:

Добавьте в связку фреймворк. Он должен загружать файл в S3 хранилище и запускать (триггерить) DAG в Airflow из предыдущего задания.
