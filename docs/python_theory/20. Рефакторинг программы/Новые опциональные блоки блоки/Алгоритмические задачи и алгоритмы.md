## Задание 1 (Легко):

### Условие:

Вам даны два целочисленных массива `nums1` и `nums2`, отсортированных в порядке  
возрастания, и два целых числа `m` и `n`, представляющих количество элементов  
в `nums1` и `nums2` соответственно.  
  
Объедините `nums1` и `nums2` в один массив, отсортированный  
в порядке возрастания.  
  
Итоговый массив имеет длину `m + n`, где первые `m` элементов обозначают  
элементы из `nums1`, а `n` из `nums2`.

### Примеры результатов:

nums1 = [1, 2, 3, 0, 0, 0]  
m = 3  
nums2 = [2, 5, 6]  
n = 3

merged_nums = [1, 2, 2, 3, 5, 6]

nums1 = [1]  
m = 1  
nums2 = []  
n = 0  
  
merged_nums = [1]


## Задание 2 (Легко):

### Условие:

Дан список из целых чисел nums, отсортированное в порядке возрастания,  
удалите дубликаты в нем так, чтобы каждый уникальный элемент появлялся  
только один раз. В итоговом списке должен быть сначала список отсортированных  
элементов, каждый элемент написан 1 раз, затем идут нижние подчеркивания '_'  
(пропуски) для того, чтобы длина списка осталось прежней.  
Функция возвращает количество уникальных элементов (k) в nums.  
  
Считайте, что количество уникальных элементов nums равно k,  
чтобы задание было выполнено корректно, вам нужно сделать следующее:  
  
1) Измените массив nums так, чтобы первые k элементов nums содержали уникальные  
элементы в том порядке, в котором они изначально присутствовали в nums.  
  
2) Остальные элементы nums это '_', чтобы длина nums сталась прежней.  
  
3) Верните k.

### Примеры результатов:

nums = [1, 1, 2]  

Вывод result_nums = [1, 2, '_']  
k = 2
