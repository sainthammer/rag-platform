
чтобы можно было сделать с объектом:

```python

	pass

```

нужно чтобы у объекта были определены два магических метода

#### _`object.__aenter__(self)`_:

Асинхронный метод `object.__aenter__()` семантически похож на [метод `__enter__()` простого менеджера контекста](https://docs-python.ru/tutorial/osnovnye-vstroennye-tipy-python/kontekstnyj-menedzher-with/ "Контекстный менеджер with в Python"), с той лишь разницей, что он должен вернуть `awaitable`.

#### _`object.__aexit__(self, exc_type, exc_value, traceback)`_:

Асинхронный метод `object.__aexit__()` семантически похож на [метод `__exit__()` простого менеджера контекста](https://docs-python.ru/tutorial/osnovnye-vstroennye-tipy-python/kontekstnyj-menedzher-with/ "Контекстный менеджер with в Python"), с той лишь разницей, что он должен возвращать `awaitable`.
