# Модуль `vector_store/` - работа с векторныйми БД

Модуль отвечает за реализацию взаимодействия с векторными БД.

В модуле частично используются методы подхода гексогональной архитектуры.

Сейчас реализованы адаптеры для ChromaDB и Qdrant.

---
